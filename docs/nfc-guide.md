# iPhone 快捷指令：NFC 触碰开关机 + Siri 语音开关机

碰一下 NFC 标签，或说一句「嘿 Siri，开机 Windows」，即可开机 / 正常关机 Windows 虚拟机。不需要副卡、不需要 Home Assistant。

**原理**：NFC 标签和 Siri 短语都只是同一个「快捷指令」的两个入口。快捷指令通过 HTTP 调用应用的 API，Token 保存在快捷指令内部（不在标签上）。

**前提**：iPhone 与 FNOS 在同一局域网（家庭 Wi-Fi）。出门流量网络下不可用。

## 准备

1. 已安装本应用并配置好端口（默认 8321；你的设备为 31011）。**小提示：应用内「NFC / Siri 快捷指令配置」帮助页中已自动填入你的真实地址，可直接复制，无需手抄。**
2. 已获得 Token（首次打开应用时在初始化页生成；或在应用「Token 管理」中重新生成）。
3. 确认手机能访问：`http://192.168.31.13:31011/api/v1/health`（浏览器打开应看到 JSON；地址以应用内显示的为准）。
4. 两个 NFC 标签（常见的 NTAG213 贴纸即可，一张贴在"开机位置"，一张贴在"关机位置"）。

## 第一步：创建「开机 Windows」快捷指令

1. 打开 iPhone「快捷指令」App → 右上角 **+**。
2. 给快捷指令命名，例如：**开机 Windows**。
3. 添加动作：搜索「**获取 URL 内容**」，添加。
4. 配置该动作：
   - URL：`http://192.168.31.13:31011/api/v1/vm/start`（地址以你实际安装的为准，可在应用内「NFC / Siri 快捷指令配置」帮助页直接复制）
   - 方法：**POST**
   - 展开「头部」→ 添加请求头：键 = `Authorization`，值 = `Bearer <你的Token>`
5. 再添加动作：「**显示结果**」，内容选「获取 URL 内容的结果」。
   - 可选：加一个「如果」动作判断返回的 `success` 等于 `true`，分别显示「已开机」/「已在运行」。
6. 点「完成」保存。

## 第二步：创建「关机 Windows」快捷指令

与开机完全相同，仅两处不同：

1. 命名 **关机 Windows**。
2. URL 改为：`http://192.168.31.13:31011/api/v1/vm/shutdown`（同样以应用内显示的为准）

其余完全一致（POST + Authorization 请求头 + 显示结果）。

## 第三步：让 Siri 可以调用（可选但推荐）

快捷指令创建后即可被 Siri 触发；为了说起来最自然，建议显式绑定短语：

1. 打开「开机 Windows」→ 右上角「…」→「**添加到 Siri**」。
2. 点 + 录制短语，例如：「**开机 Windows**」。
3. 同样给「关机 Windows」绑定：「**关机 Windows**」。

之后说「嘿 Siri，开机 Windows」即可触发。

> iOS 15+ 也可以直接说「嘿 Siri + 快捷指令名称」；显式录制短语更稳定。锁屏可用性受「设置 → Siri → 允许 Siri 在锁定时使用」影响；解锁状态确认等行为因 iOS 版本而异，请以你实际设备为准。

## 第四步：创建 NFC 自动化

把 NFC 标签接到上面两个快捷指令上：

1. 「快捷指令」App → 底部「自动化」→ 右上角 **+** →「个人自动化」。
2. 向下滑，选择「**NFC**」。
3. 点「扫描」，将开机标签贴到 iPhone NFC 感应区（顶部，靠近后置摄像头）。
4. 给标签命名（如"开机标签"）→ 下一步。
5. 添加动作：搜索「**运行快捷指令**」→ 选择「**开机 Windows**」。
6. 关闭「运行前询问」（如 iOS 版本提供该选项），完成。
7. 关机标签同理：自动化 → NFC → 选择关机标签 → 「运行快捷指令 → 关机 Windows」。

> NFC 触发和 Siri 触发复用同两条快捷指令，Token 只需维护一处：改了 Token 或端口，更新「开机/关机 Windows」两条指令即可。

## 第五步：实际使用

- 碰开机标签（或说「嘿 Siri，开机 Windows」）→ 快捷指令 POST → Windows 开机；返回 JSON 用「显示结果」弹出（含 `state` 与 `message`）。
- 碰关机标签（或说「嘿 Siri，关机 Windows」）→ Windows 正常关机；关机过程需要时间（默认等待最多 120 秒），快捷指令会在收到响应后显示结果。

## 常见情况

| 情况 | 表现 |
|---|---|
| 已开机又触发开机 | 返回 `success: true, already: true, message: "虚拟机已在运行中"`，不会重复开机 |
| 已关机又触发关机 | 返回 `success: true, already: true` |
| Windows 关不掉（超时） | 返回 `success: false, timed_out: true`，未强制断电，请检查 Windows |
| 返回 401 | Token 错误或已更新；重新复制最新 Token 替换请求头（两条快捷指令都要改） |
| 网络不通 | 确认 iPhone 在家庭 Wi-Fi，未用蜂窝/流量 |

## 端口修改后怎么办

1. 应用中心 → FNOS VM Remote → 设置，修改服务端口并保存。
2. 修改「开机 Windows」「关机 Windows」两个快捷指令里「获取 URL 内容」的 URL 端口。
3. Token 不用改。

## 限制说明（重要）

- **NFC 标签不存 Token**，仅触发器；Token 泄露风险取决于你如何保护快捷指令本身。
- 快捷指令访问 NAS **必须处于家庭局域网**；出差/在外用蜂窝网络无法触达。
- **iOS 版本差异**：不同 iOS 版本对 NFC 自动化的运行确认、解锁状态、后台运行策略存在差异（部分版本需解锁并点一下确认），**请以你的 iPhone 实际行为为准**，本文不承诺完全无交互。
- 关机 API 会等待直到 Windows 确实关机或超时；如果 Windows 正在更新/卡住，快捷指令会等到超时才返回——这是正常行为，不会强制断电。

## 排错

1. 快捷指令"获取 URL 内容"报错 → 先在 iPhone Safari 打开 `http://192.168.31.13:31011/api/v1/health` 验证网络可达（地址以应用内显示的为准）。
2. 返回 401 → Token 不对，复制粘贴时注意不要带前后空格。
3. 返回成功但 VM 没反应 → 应用日志（应用内「操作日志」可看到每次请求的结果）；或确认你触发的是对应的那条快捷指令（NFC 和 Siri 是否绑定了同一条）。
