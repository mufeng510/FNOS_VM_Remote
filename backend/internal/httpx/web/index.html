如何修改服务端口？

端口不在本页面直接修改，请按以下步骤操作（FNOS 官方联动方式，保证桌面入口与服务一致）：

  1. 打开 FNOS 应用中心 →「FNOS VM Remote」→ 设置。
  2. 修改「服务端口」并保存。
  3. 应用会自动重启并监听新端口，桌面入口地址随之更新；端口被占用或非法时会给出明确提示并回滚。
  4. 如使用 iPhone 快捷指令，请同步更新快捷指令中的 URL 端口。
